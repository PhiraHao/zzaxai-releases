# ZzaxAi — ตัวติดตั้ง

ที่เก็บนี้มีไว้แจกไฟล์ติดตั้งของ **ZzaxAi** เท่านั้น ไม่มีซอร์สโค้ด

ดาวน์โหลดรุ่นล่าสุดได้ที่ [zzaxai.com](https://zzaxai.com/#download) หรือที่หน้า [Releases](../../releases/latest)

| ไฟล์ | ใช้กับ |
|---|---|
| `ZzaxAi-Setup-Windows.exe` | Windows 10 / 11 (64 บิต) |
| `ZzaxAi-macOS-AppleSilicon.dmg` | แมคชิป Apple (M1 ขึ้นไป) |
| `ZzaxAi-macOS-Intel.dmg` | แมคชิป Intel |

ใช้ฟรี ไม่ต้องสมัครสมาชิก ไม่มีรุ่นเสียเงิน

## เปิดครั้งแรกบนแมค

ตั้งแต่รุ่น 1.4.1 แอปเซ็นชื่อด้วยใบรับรองนักพัฒนาของ Apple และผ่านการตรวจของ Apple แล้ว
ลากแอปเข้า Applications แล้วดับเบิลคลิกได้เลย จะขึ้นกล่องถามครั้งเดียวว่า

> **“ZzaxAi” เป็นแอปที่ดาวน์โหลดมาจากอินเทอร์เน็ต คุณแน่ใจหรือไม่ว่าคุณต้องการเปิด**
> Apple ได้ตรวจสอบแอปเพื่อตรวจหาซอฟต์แวร์ที่ประสงค์ร้ายแต่ตรวจไม่พบซอฟต์แวร์ใดๆ ที่ประสงค์ร้าย

กด **เปิด** ครั้งต่อไปจะไม่ถามอีก **ไม่ต้องพิมพ์คำสั่งใน Terminal แล้ว**

<details>
<summary>ถ้ายังใช้ไฟล์รุ่น 1.4.0 หรือเก่ากว่า</summary>

รุ่นก่อน 1.4.1 ยังไม่ได้เซ็นชื่อ ตอนเปิดจะขึ้นว่า

> **“ZzaxAi” เสียหายและเปิดไม่ได้ คุณควรย้ายรายการไปยังถังขยะ**

ไม่ใช่ไฟล์เสีย กล่องนี้มีสองปุ่ม **กด “ยกเลิก” อย่ากด “ย้ายไปยังถังขยะ”**
แล้วเปิด Terminal วางคำสั่งนี้หนึ่งครั้ง

```
xattr -dr com.apple.quarantine /Applications/ZzaxAi.app
```

หรือโหลดรุ่น 1.4.1 ขึ้นไปซึ่งไม่ต้องทำอะไรเลย

</details>
